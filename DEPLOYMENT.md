# Deploying jama-go

`npm run build` outputs to `dist/jamago-security/browser/`. Upload that directory
as before — there is no Node server to run.

## One nginx change is required

The public pages are now **prerendered to static HTML at build time**, so the
output contains real pages rather than a single empty shell:

```
dist/jamago-security/browser/
├── index.html            ← the prerendered HOME page
├── contact/index.html    ← prerendered
├── sifeddine/index.html  ← prerendered
└── index.csr.html        ← empty shell, for everything else
```

The SPA fallback must now point at **`index.csr.html`**, not `index.html`.

If it keeps falling back to `index.html`, a visitor opening `/admin/login`
directly is served the prerendered *home page* markup first, sees the marketing
site for a moment, and only then gets routed to the login screen once Angular
boots.

```nginx
server {
    root /var/www/jamago/browser;

    # Hashed build assets never change; the fonts are content-addressed by name.
    location ~* \.(?:js|css|woff2|png|jpe?g|svg|webp)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # Prerendered pages resolve as real files or directories; anything else is
    # a client-rendered route and gets the empty shell.
    location / {
        try_files $uri $uri/index.html $uri/ /index.csr.html;
    }
}
```

Two other things worth having on that server block, neither of which the app can
set for itself:

- **gzip or brotli** for `text/html`, `application/javascript` and `text/css`.
  Fonts are `.woff2` and already compressed — do not re-compress them.
- **A 301 between `jamago.qa` and `www.jamago.qa`.** Both currently resolve. If
  both stay reachable, Google indexes two copies of the site and splits the
  ranking between them.

## Fonts

Self-hosted under `public/fonts/`, generated by `scripts/fetch-fonts.mjs`. They
are committed, so a normal build needs no network access. Re-run that script
only when a weight or family is added to the design.
